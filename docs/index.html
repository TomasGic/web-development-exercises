Todo List Appp

What is it?
A lightweight task manager app built with html, css and javascript. It allows users to add and remove tasks, mark tasks as complete, undo selection and clear completed tasks in bulk.
What does it demonstrate?
Event delegation (attaching event listeners to entire `
    ` element instead of concrete button elements inside `
      `), DOM manipulation, dynamic class toggling and real-time state counting.
What should I notice?
Notice the thoughtful singular/plural handling (task vs tasks) and distinct empty states ("You don't have any tasks").

Design System - Products Page

What is it?
A fully responsive products page of a fictitious clothing brand designed in Figma and built using a visual design tokens system.
What does it demonstrate?
Ability to translate a UI/UX design to a fully responsive HTML page.
What should I noticed?
Smooth, gradual transition of the font-size inside the hero section at different screen widths thanks to using vw units and the css clamp function.
